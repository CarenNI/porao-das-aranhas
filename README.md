# Porão das Aranhas

Jogo do projeto de Jogos Digitais II (2026/2).

## A carta

* **Tema:** Porão com aranhas de poeira
* **Tipo:** Chefe — resistir às ondas até o chefe surgir, e derrotá-lo
* **Modo:** Horda (arena vista de cima)

## Como jogar

* \- Setas ou WASD: andar
* \- Espaço: atacar com a foice
* \- Objetivo: aguente as ondas de aranhas de poeira. Aos 60 segundos chega a aranha-rainha e as ondas param; derrote-a (6 golpes) para vencer. Se a sua vida (5) acabar, você perde.
