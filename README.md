# Porão das Aranhas

Jogo do projeto de Jogos Digitais II (2026/2).

## A carta
- **Tema:** Porão com aranhas de poeira
- **Tipo:** Chefe — resistir às ondas até o chefe surgir, e derrotá-lo
- **Modo:** Horda (arena vista de cima)

## Como jogar
- Setas ou WASD: andar
- (o ataque e o objetivo entram nas próximas aulas)
